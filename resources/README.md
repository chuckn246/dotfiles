# Resources

Additional configuration resources that do not fit into the normal dotfile structure.

----

## Terminal Profiles

The `terminal-app` directory contains Apple Terminal.app color profiles.

Included profiles:

- Ayu Light
- Everforest Dark Hard
- Everforest Light Hard
- Nord
- Rose Pine Dawn
- Solarized Light

These profiles can be imported into Terminal.app:

1. Open **Terminal.app**
2. Go to **Terminal → Settings → Profiles**
3. Click the **Actions** menu (gear icon)
4. Select **Import...**
5. Choose a `.terminal` file

After importing, the profile can be selected as the default profile or assigned to specific windows/tabs.

----

## Notes

These profiles are macOS-specific and are not required for the shell configuration to function.

They are kept here as personal workstation resources and can be installed manually after bootstrapping the rest of the dotfiles.
