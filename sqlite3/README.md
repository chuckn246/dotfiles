## sqlite3 Dotfiles

`sqlite3` configuration

Check if settings were applied, run this from the sqlite3 prompt:
- `.show`: displays current settings like headers, mode, width, and nullvalue.
- `PRAGMA compile_options;`: lists compile-time options used to build SQLite.
- `PRAGMA journal_mode;`: checks the current journaling configuration.
- `PRAGMA synchronous;`:  shows the current disk synchronization.
